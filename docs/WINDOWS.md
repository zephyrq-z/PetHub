# 桌宠合集 · Windows 版使用说明

薄肌 · 太对了 · 峰哥 · 果冻，四只桌宠住在一个 App 里。点一下就说，凑在一起会接话。
这一页只讲 Windows 版怎么装、怎么玩、哪里和 macOS 版不一样。

## 装

Windows 10 / 11（x64）。两种包，选一个：

| 文件 | 用法 |
| --- | --- |
| `PetHub-2.0.0-Windows-x64.exe` | **单文件便携版**：双击就运行，不安装。每次启动会先解压到临时目录，慢一两秒。 |
| `PetHub-2.0.0-Windows-x64.zip` | 免安装版：解压到任意文件夹，双击里面的 `PetHub.exe`。启动更快，适合长期用。 |

第一次运行可能弹 **Windows SmartScreen「已保护你的电脑」**：点「更多信息」→「仍要运行」。
这是因为 exe 没有买代码签名证书，不是有毒。介意的话可以自己用

```
certutil -hashfile PetHub-2.0.0-Windows-x64.exe SHA256
```

和发布页的 `PetHub-2.0.0-Windows-x64.sha256` 对一下。

启动后：四只出现在屏幕右下角，**任务栏托盘**多一个「桌宠合集」图标；不占任务栏按钮，也没有开始菜单项。

## 怎么玩

| 操作 | 结果 |
| --- | --- |
| 单击薄肌 / 太对了 / 峰哥 | 随机说一句，带字幕和说话动画；一轮播完再重来，不会连着重复 |
| 点一下薄肌起头 | 四步捧哏：薄肌 → 太对了 → 峰哥 → 太对了，第四句之后收住，不会无限接 |
| 拖动薄肌 / 太对了 / 峰哥 | 换个位置待着，退出后还记得 |
| 右键语音三只 | 随机说一句、挑一句、播放方式、轮播内容、停止播放、音量、大小、移回右下角、隐藏 |
| 按住 / 拖动果冻 | 以按压点为中心弹一下、肿一块，拖开朝光标方向拉长，松手 Q 弹归位；它只是原地形变 |
| 右键果冻 | 回到原位、大小、图标（Claude / GPT / Gemini）、隐藏果冻 |
| 右键托盘图标 | 总菜单：显示 / 隐藏、四只子菜单、捧哏联动、大小联动、绑定相对位置、大小、排列、自定义桌宠、设置、关于、退出 |
| 双击托盘图标 | 打开设置窗口 |

四只的默认站位是屏幕右下角一排（薄肌 → 太对了 → 峰哥 → 果冻）；「全部归位」随时回到这一排。

### 托盘 / 设置里的开关

- **显示 / 隐藏**：单独控制四只，或全部显示 / 全部隐藏。
- **捧哏联动**：关掉后四只不再互相接话，各自点各自说。
- **大小联动**：默认开。拖任意一只的大小滑块，另外三只按同一比例一起变；关掉后各改各的。
- **绑定相对位置**：默认关。打开后拖任意一只语音桌宠，四只保持队形一起移动（果冻自身仍是原地 Q 弹）。
- **大小**：50%–180%，默认 100%。托盘里是几档预设，设置窗口里是无级滑块；四只比例不同，
  滑块说的是「相对各自默认大小的比例」，不会强行拉成同样像素。
- **排列**：全部归位（默认）/ 紧凑排列（间距收拢）/ 捧哏排列（合影站位：薄肌左、太对了中间抬高、
  峰哥右、果冻缩在峰哥右肩后）。
- **设置窗口**：托盘右键「设置…」或双击托盘图标。所有开关和四只的大小/音量都能在这里调，
  还能导入自定义桌宠、打开内容包文件夹、看关于和版权。

所有设置自动保存在本机：

```
%APPDATA%\PetHub\settings.json
```

## 把薄肌换成你自己的角色（PetPack）

1. 准备一个文件夹，里面有 `petpack.json`、一张头像、若干条语音（格式见
   [PETPACK.md](PETPACK.md)，仓库里还有 `Examples/MyTeacher/` 模板）。
2. 托盘右键 →「自定义桌宠」→「导入 petpack.json 文件夹…」，选中**包含 `petpack.json` 的那一层**文件夹。
3. 校验通过后，薄肌立刻换成你的角色：头像、名字、语音、字幕都来自内容包；太对了 / 峰哥 / 果冻不变。
4. 随时可以「恢复原版薄肌」删掉内容包，回到内置 37 句。

规则：

- 只替换**薄肌槽位**，一次只能装一个包；再导入会覆盖上一个。
- 导入时会完整校验：`format = 1`、1–200 条语音、路径安全（不含 `..` / 绝对路径）、
  每条语音有中文、头像可解码、音频可解码且时长 > 0.1 秒。坏包会被拒绝，**不会**把正在用的角色弄坏。
- 装好的内容包在 `%APPDATA%\PetHub\HeadPet\`；整个文件夹拷出来就是一个可分发的标准 PetPack。
- 自定义角色起头的四步链不变：你的角色（内部仍是薄肌）→ 太对了 → 峰哥 → 太对了，第四句收住。
- 内容包只提供数据（头像 / 音频 / 文字），不能携带或执行代码；App 不上传、不联网。

## 和 macOS 版的差异

Windows 版是 Electron + 原生 HTML/CSS/JS 的重写，不是把 macOS App 直接搬过来。玩法、联动策略、
素材和内容包格式都一样，界面和少数功能有差异：

- **托盘菜单 + 设置窗口**代替 macOS 的菜单栏状态项。
- **没有机身摇晃**：那是 macOS 笔记本 SPU 加速度计的私有接口，Windows 版不实现。
- **果冻更简化**：按压放大、拖动拉长、松手回弹、图标切换都有，但没有 macOS 版的 CoreImage 鼓包效果。
- **没有自定义角色编辑器**：macOS 版可以现场填名字 / 选头像 / 加语音；Windows 版只支持
  「导入现成 PetPack」和「恢复原版」。
- **右键菜单的「轮播内容」勾选**：Windows 原生菜单点一次就关，要勾好几条得重开几次；
  连续调大小请用设置窗口的滑块。
- **接话重叠略紧一点点**：macOS 会逐句量开头静音再补偿，Windows 版用时长减重叠近似；
  hop / root / 能接谁 / 第几句话都完全一致。
- **设置不互通**：Windows 用 `%APPDATA%\PetHub\settings.json`，macOS 用 UserDefaults，互不迁移。
- **未做 Windows 实机验收**：开发与自动测试都在 macOS（含打包后的 smoke），透明窗口、置顶、
  DPI 缩放、托盘在真实 Windows 上请以实际体验为准；遇到问题欢迎开 issue。

## 常见问题

**双击后没反应 / 闪退？**
先看是不是 SmartScreen 拦了；再从终端（PowerShell）运行 `PetHub.exe` 看输出。
如果装的是单文件便携版，等几秒解压；杀毒软件误报自解压 exe 时，换 zip 版。

**只有托盘图标，四只不见了？**
托盘右键 →「全部显示」或「全部归位」。多显示器拔插后，位置可能落在屏幕外，用「全部归位」找回。

**点四只没有声音？**
右键对应桌宠 →「音量」看看是不是静音了；系统音量 / 输出设备也检查一下。

**果冻挡住桌面点击？**
果冻窗口比图标大一圈，但只有图标附近接收点击，其余区域应该穿透到桌面。
如果某个 Windows 版本上穿透失效，把果冻隐藏掉或用「大小」调小。

**怎么完全卸载？**
便携版：退出后删掉 exe 即可。zip 版：删掉解压出来的文件夹。设置和内容包在
`%APPDATA%\PetHub\`，想彻底清干净就一起删。

**会和 macOS 版 / 原来四个独立 App 互相接话吗？**
不会。联动只在同一个 App 进程里；两套同时开还会在屏幕上叠着。
