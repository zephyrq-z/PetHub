# 做你自己的桌宠（2.0）

不用写代码，也不用重新编译。准备一张头像、几条语音、每条语音配一句中文，就能把合集里的**薄肌**
换成你自己的角色——比如「我的老师」。太对了、峰哥、果冻都不受影响，捧哏链照旧。

> 想直接看格式细节：[PETPACK](PETPACK.md)。想复用内核写代码：[ARCHITECTURE](ARCHITECTURE.md)。

## 你能得到什么

- 桌面上的薄肌位置，换成你的头像和名字；
- 点一下随机说一句你的语音，字幕显示你配的中文；
- 右键菜单里能「挑一句」「轮播内容」「调音量」「大小滑块」——和原来一样；
- 你点它起头，**太对了和峰哥照样接话**：你的角色 → 太对了 → 峰哥 → 太对了，四步链不变；
- 随时「恢复原版薄肌」，回到内置的 37 句。

只能换薄肌这一个位置；太对了、峰哥、果冻暂时不能用自己的素材替换。

## 准备素材

1. **头像**：一张图片，推荐透明底 PNG、方形、脸在中间，例如 `teacher.png`。
   支持 png / jpeg / tiff / heic / gif。
2. **语音**：1–200 条，推荐 wav / m4a / mp3 / aiff。每条不用长，1–5 秒最跟手。
3. **中文**：每条语音配一句话，会显示在字幕里，例如「同学们好」「下课」。

素材版权自己负责；用别人的照片或录音前先确认授权（见 [NOTICE](../NOTICE.md)）。

## 三步换掉薄肌（以「我的老师」为例）

### 1. 打开编辑器

点菜单栏右侧的「桌宠」→「自定义桌宠」→「换成我的角色…（替换薄肌）」。

会打开「自定义桌宠 · 替换薄肌」窗口。第一次打开时名字默认是「我的老师」，可以改。

### 2. 填名字、选头像、加语音

1. 在「名字」里填 `我的老师`。
2. 点「选择头像图片…」，选一张图。
3. 点「添加语音…」，可以一次多选几个音频文件；每加一条，列表里多一行。
4. 在每行右边的输入框里填这条语音对应的中文（默认是文件名，记得改成真正要显示的字幕）。
5. 加错了点那一行的「删除」。

### 3. 保存并应用

点「保存并应用」。窗口会关掉，桌面上的薄肌**立刻**变成你的角色，不用重启 App。

如果弹出错误，通常是：没选头像、没起名字、一条语音都没有、某条语音没填中文，
或者音频/图片读不出来。按提示补上即可；保存失败不会破坏你原来的设置。

## 效果长什么样

- 桌面上原来薄肌的位置，换成你的头像；
- 点一下，随机播一条你的语音，字幕显示你填的中文；
- 右键菜单标题变成「我的老师 · 自定义 · N 句」，其他设置项照旧；
- 菜单栏「显示 / 隐藏」和四只的子菜单里，这一只显示成你起的名字；
- 点它起头，太对了会接一句，峰哥再接，太对了再接——四步链和点原版薄肌完全一样；
- 大小、音量、位置、轮播勾选照样记住。

## 换成别人做好的内容包

如果你拿到一个带 `petpack.json` 的文件夹：

1. 菜单栏「桌宠」→「自定义桌宠」→「导入 petpack.json 文件夹…」；
2. 选中**包含 `petpack.json` 的那一层文件夹**（不是里面的 `clips`）；
3. 校验通过后立刻替换薄肌。失败会弹窗说明原因，原来的角色不受影响。

## 恢复原版薄肌

两种方式等价：

- 菜单栏「桌宠」→「自定义桌宠」→「恢复原版薄肌」；
- 再打开编辑器，点左下角「恢复原版薄肌」。

会删掉当前自定义内容，薄肌回到内置的 37 句。之后想再用，重新选素材保存即可
（之前的内容不会自动备份，重要的包先按下一节拷出来）。

## 文件在哪

自定义内容只存在你自己的 Mac 上：

```
~/Library/Application Support/PetHub/HeadPet/
├── petpack.json
├── avatar.<扩展名>
└── clips/
    └── 01.<扩展名> …
```

- 菜单栏「桌宠」→「自定义桌宠」→「打开内容包文件夹」会打开它的上级目录
  `~/Library/Application Support/PetHub/`。
- 想备份或分享：把 `HeadPet` 文件夹整个拷出来、压成 zip 就是标准内容包，别人用
  「导入 petpack.json 文件夹…」就能装。
- 想彻底清掉：退出 App 后把 `HeadPet` 文件夹删掉，下次启动就是原版薄肌。

## 隐私

App 不上传任何东西、不联网。头像和语音只在本机被读取、复制到上面的目录，
不会发到服务器；摇晃功能之外也没有别的网络通信。

## 常见问题

**Q：为什么只能换薄肌？**
A：薄肌是四步捧哏链的链头。它换成谁，内部身份仍然是 `.shaolan`，所以太对了/峰哥的接话条件
不用改，链不会断。换太对了或峰哥会改变链的起点，暂时没有做。

**Q：换完之后太对了、峰哥还接话吗？**
A：接。你点自定义角色起头，它就是 hop 0、root 薄肌，后面照旧：太对了 → 峰哥 → 太对了，第四句收住。

**Q：能放多少条语音？**
A：1–200 条。太少没意思，太多没必要——随机池会一轮内不重复地播。

**Q：我的音频是 mp3，可以吗？**
A：可以。编辑器支持 wav / m4a / mp3 / aiff；只要系统能解码且时长超过 0.1 秒。

**Q：头像要抠图吗？**
A：不用。透明底 PNG 效果最好；App 不裁剪，按原图比例显示。

**Q：保存后没变化？**
A：先确认弹窗没报错；再看菜单栏「自定义桌宠」是否显示「当前：我的老师（替换薄肌）」。
仍有问题就重启 App 再试。

**Q：启动时提示内容包不可用 / App 起不来？**
A：通常是手动改了 `HeadPet/` 里的文件导致校验失败。删掉
`~/Library/Application Support/PetHub/HeadPet/` 再启动即可回到原版。

**Q：能分享给朋友吗？**
A：可以。把 `HeadPet` 文件夹压成 zip 发给对方，对方用「导入 petpack.json 文件夹…」安装。
你们要自己确保头像/声音/文字的版权没问题。
