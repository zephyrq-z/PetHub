# MyTeacher · 内容包模板

这是一个 **PetPack 内容包模板**：把薄肌换成「我的老师」。
仓库里只放模板和文字，**不放头像、音频等二进制素材**（版权和仓库体积都不合适）。

格式规范：[docs/PETPACK.md](../../docs/PETPACK.md)
普通用户步骤：[docs/MAKE_YOUR_OWN_PET.md](../../docs/MAKE_YOUR_OWN_PET.md)

## 目录

```
MyTeacher/
├── petpack.json     ← 模板，字段说明见下
├── avatar.png       ← 需要你自己放（当前不存在）
└── clips/           ← 需要你自己放音频
    ├── 01.m4a
    ├── 02.m4a
    └── 03.aiff
```

`petpack.json` 里的路径都是相对这个文件夹的。

## 怎么用

1. 把整个 `MyTeacher/` 文件夹复制到你自己的工作目录（别直接在仓库里加素材）。
2. 放一张头像，命名成 `avatar.png`（JPEG/HEIC 也可以，但要把 json 里的 `avatar` 一起改）。
3. 把语音放进 `clips/`，按 `01.m4a`、`02.m4a`、`03.aiff` 命名；
   或者用你自己的文件名，但要同步改 `petpack.json` 的 `clips[].file`。
4. 把每条语音的中文写进 `clips[].label`，例如「同学们好」「下课」。
5. 打开桌宠合集 → 菜单栏「桌宠」→「自定义桌宠」→「导入 petpack.json 文件夹…」，
   选中这个 `MyTeacher/` 文件夹。
6. 导入成功后薄肌立刻变成你的角色；菜单「恢复原版薄肌」可以还原。

> 模板本身**不能直接导入**：`avatar.png` 和 `clips/` 里的音频不存在时，App 会按
> 「桌宠包缺少文件」拒绝。先补齐素材再导入。

## 文件命名和顺序

- 编号只由 `clips` 数组顺序决定，不由文件名决定；`01`、`02` 只是方便人看。
- 数量范围 1–200 条。
- 音频推荐 wav / m4a / mp3 / aiff；要求系统能解码且时长 > 0.1 秒。
- 中文不能为空；字幕会原样显示。

## 检查 JSON

```bash
python3 -m json.tool petpack.json
```

或直接用应用导入，校验错误会给出具体是哪个文件/哪条语音的问题。
